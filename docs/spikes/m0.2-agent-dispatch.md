## Fallbacks

- **If the Grok API cannot return a usable verdict:** QA moves to another non-Claude model behind the same OpenAI-compatible call. Options: an open-weight model on a self-hosted server (Ollama, vLLM). OpenRouter is not chosen (D-142). The script needs no change, only different settings. This also keeps QA on a different model family from the Developer (P-04).
- **If Claude Code's CLI is a no:** use the Agent SDK in the same process. It reports the same fields.
- **If Cursor is a no:** nothing changes. Cursor has no role (D-119).

## How the scripts check the answer themselves

- `claude-code.ts` asks for one file and then checks the file on disk. It does not trust the agent's report (evidence from outside the agent).
- `qa-verdict.ts` sends a diff with a known off-by-one defect. A verdict is only accepted if it is valid JSON, says pass or fail, lists findings, and names the commit it was given. A "pass" is recorded as a wrong verdict.
- Every script enforces its own time limit. The runner must never wait on an agent forever.
