# M0.4 spike: Windmill approval pages on a phone (V-03)

- **Question:** can Didi open a Windmill approval page on his phone, answer it in his own words, and have the flow resume with his exact reply and a timestamp?
- **Status:** desk result, 2026-10-28. **Not run yet.** This spike is Didi's to judge: he tries the page on his phone and decides whether the channel is good enough (review point).
- **Flow:** [`spikes/m0.4-windmill-approval/hello-approval.flow.yaml`](../../spikes/m0.4-windmill-approval/hello-approval.flow.yaml). Import it into a throwaway Windmill workspace folder.

## Desk results

Sources: Windmill's OpenFlow spec and API spec, its TypeScript client (`getResumeUrls`), and its flow-writing guide, all from `github.com/windmill-labs/windmill`; plus search summaries of windmill.dev pages, which could not be opened from this cloud session.

| Capability                                  | Provisional answer   | Evidence                                                                                                                                                                                                                    |
| ------------------------------------------- | -------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Suspend a flow and resume it from a link    | **Yes**              | A `suspend` block on a step, with `timeout`. `getResumeUrls()` returns an approval page, a resume link and a cancel link.                                                                                                   |
| A typed reply that the next step reads      | **Yes, in the spec** | `resume_form.schema` defines the form. The next step reads `resume` (the reply) and `approvers`.                                                                                                                            |
| Open it on a phone without logging in       | **Likely yes**       | The approval page is protected by a signed token in the link, so no Windmill login is needed unless `user_auth_required` is set. Send the approval page, not the raw resume link: email link scanners can trigger a resume. |
| Typed-reply forms on a free Cloud workspace | **Unclear**          | Windmill's pricing lists approval forms and approver restrictions among paid features. The run must show whether the form appears on the free plan.                                                                         |
| Only Didi can approve                       | **Paid feature**     | Requiring a login, limiting approvers to a group, and blocking self-approval are listed for Cloud paid and Enterprise plans.                                                                                                |

## A finding that affects more than this spike

A 5-minute reconcile loop (D-111) is 288 runs a day, about 8,640 a month. Third-party sources put the free Windmill Cloud tier at about 1,000 executions a month. If that is right, the free tier cannot run the loop. The options are a paid Cloud plan, self-hosting Windmill, or a longer interval. Spending money is Didi's decision, so this is logged as an open question (N-19) in `docs/decision-log.md`. The official limit could not be read from this session and must be checked on windmill.dev. **Since then:** Didi confirmed 1,000 executions a month on windmill.dev, and the loop runs every 2 hours until Kubernetes (D-164).
